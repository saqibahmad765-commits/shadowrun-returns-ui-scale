# UI Scale 1.1.0

Configurable combined UI/text scaling for Shadowrun Returns with BepInEx 5.4.23.2 x86.

- F9 reloads saved configuration; F10 toggles original/configured UI size.
- Guards native F9 load-screen and F10 diagnostic shortcut conflicts.
- Preserves the existing scale setting and original scaling algorithm.
- F8 remains a native game resolution shortcut: do not use it to adjust UI Scale.

Download **UIScale-1.1.0.zip** from the release assets, not GitHub's automatic source ZIP. Close the game and extract into its installation folder, replacing the old UIScale DLL. Requirements, configuration and removal instructions are inside the ZIP.

F10 is user-tested; F9 reload is confirmed by the runtime log. Nine scale-boundary tests passed. Full layout/compatibility coverage and direct observation of all shortcut side effects remain incomplete. Developed against an Electric 6.2-modified installation, not validated against an unmodified game.

SHA256SUMS.txt identifies the archive and extracted DLL. Checksums establish identity, not security clearance. This release contains the same DLL as the user's tested 1.1.0 installation, with updated documentation and the MIT license.

Developed with OpenAI Codex assistance for code, documentation and packaging, with requirements and in-game testing provided by the mod author.
